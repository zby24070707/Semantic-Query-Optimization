## 1. LLM-Extended Query Processing Systems

**[1.1] Sema-SQL: Extending Relational Queries with Large Language Models.** 

*Yin Lin, Tianjing Zeng, Zhongjun Ding, Rong Zhu, Bolin Ding, H. V. Jagadish, Jingren Zhou. Alibaba Group & University of Michigan. arXiv, 2026.* [[paper](https://arxiv.org/abs/2604.23477)]

**[1.2] Palimpzest: Optimizing AI-Powered Analytics with Declarative Query Processing.** 

*Chunwei Liu, Matthew Russo, Michael Cafarella, Lei Cao, Peter Baile Chen, Zui Chen, Michael Franklin, Tim Kraska, Samuel Madden, Rana Shahout, Gerardo Vitagliano. MIT, University of Arizona, University of Chicago & Harvard University. CIDR, 2025.* [[paper](https://arxiv.org/abs/2405.14696)] [[code](https://github.com/mitdbg/palimpzest)]

**[1.3] Cut Costs, Not Accuracy: LLM-Powered Data Processing with Guarantees (BARGAIN).** 

*Sepanta Zeighami, Shreya Shankar, Aditya Parameswaran. UC Berkeley. SIGMOD (PACMMOD), 2025.* [[paper](https://arxiv.org/abs/2509.02896)]

**[1.4] Semantic Data Processing with Holistic Data Understanding (HoldUp).** 

*Youran Sun, Sepanta Zeighami, Bhavya Chopra, Shreya Shankar, Aditya G. Parameswaran. UC Berkeley. arXiv, 2026.* [[paper](https://arxiv.org/abs/2604.02655)]

**[1.5] SABER: A SQL-Compatible Semantic Document Processing System Based on Extended Relational Algebra.** 

*Changjae Lee, Zhuoyue Zhao, Jinjun Xiong. University at Buffalo. PVLDB, 2025.* [[paper](https://arxiv.org/abs/2509.00277)]

**[1.6] QUEST: Query Optimization in Unstructured Document Analysis.** 

*Zhaoze Sun, Qiyan Deng, Chengliang Chai, Kaisen Jin, Xinyu Guo, Han Han, Ye Yuan, Guoren Wang, Lei Cao. University of Arizona, MIT & Beijing Institute of Technology. PVLDB, 2025.* [[paper](https://arxiv.org/abs/2507.06515)]

**[1.7] ScaleDoc: Scaling LLM-based Predicates over Large Document Collections.** 

*Hengrui Zhang, Yulong Hui, Yihao Liu, Huanchen Zhang. Tsinghua University. SIGMOD, 2026.* [[paper](https://arxiv.org/abs/2509.12610)]

## 2. Semantic Operator Methods

**[2.1] Semantic Operators and Their Optimization: Enabling LLM-Based Data Processing with Accuracy Guarantees in LOTUS.** 

*Liana Patel, Siddharth Jha, Parth Asawa, Melissa Pan, Harshit Gupta, Carlos Guestrin, Matei Zaharia. Stanford University & UC Berkeley. PVLDB, 2025.* [[paper](https://www.vldb.org/pvldb/vol18/p4171-patel.pdf)]

**[2.2] Implementing Semantic Join Operators Efficiently.** 

*Immanuel Trummer. Cornell University. arXiv, 2025.* [[paper](https://arxiv.org/abs/2510.08489)]

**[2.3] SemJoin: Semantic Join Optimization.** 

*Christopher Gou, Aditya Banerjee, Jiaxuan Wang, Chunwei Liu. Purdue University. VLDB Workshop (NOVAS), 2026.* [[paper](https://arxiv.org/abs/2606.29532)]

**[2.4] Large Language Model-Enhanced Relational Operators: Taxonomy, Benchmark, and Analysis.** 

*Yunxiang Su, Tianjing Zeng, Zhongjun Ding, Yin Lin, Rong Zhu, Zhewei Wei, Bolin Ding, Jingren Zhou. Alibaba Group & Renmin University of China. arXiv, 2026.* [[paper](https://arxiv.org/abs/2603.02537)]

**[2.5] Larch: Learned Query Optimization for Semantic Predicates.** 

*Fuheng Zhao, Paweł Liskowski, Zihan Li, Benjamin Han, Puxuan Yu, Varich Boonsanong, Dimitris Tsirogiannis, Anupam Datta. Snowflake Inc. arXiv, 2026.* [[paper](https://arxiv.org/abs/2606.07923)]

**[2.6] Towards a Unified Framework for String Similarity Joins.** 

*Pengfei Xu, Jiaheng Lu. University of Helsinki. PVLDB, 2019.* [[paper](https://www.vldb.org/pvldb/vol12/p1289-xu.pdf)] [[code](https://github.com/HY-UDBMS/AU-Join)]
